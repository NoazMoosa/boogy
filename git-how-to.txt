bash cli command line:  (move terminal to be in the git directory)
$ cd <path to directory>  

Pull latest master version from cloud to local:
$ git pull

Create a new branch:
$ git checkout -b BRANCH-NAME

When you want to push the changes to the cloud:
1. Stage to commit - Add all the files you want to be added/modified in the branch. 
If it's all changed/added files just do:
$ git add .

(If you want only specific files, replace '.' with the file names)

2. Commit - save all the changes to the local branch
$ git commit -m "commit_message"

3. Push to the cloud branch
$ git push
